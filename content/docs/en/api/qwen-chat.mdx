## 📝 Introduction

Given a list of messages comprising a conversation, the model will return a response. Qwen is a large-scale language model independently developed by the Tongyi Lab under Alibaba Group, supporting multilingual conversations, text generation, code generation, and more.

## 🤖 Supported Models

Currently supported models include:

| Model | Description |
| --- | --- |
| **qwen-turbo** | Qwen Turbo chat model |
| **qwen-plus** | Qwen Plus chat model |
| **qwen-max** | Qwen Max chat model |
| **qwen3.5-flash** | Qwen 3.5 Flash chat model |
| **qwen3.5-plus** | Qwen 3.5 Plus chat model |
| **qwen3.6-plus** | Qwen 3.6 Plus chat model |
| **qwen3.7-max** | Qwen 3.7 Max chat model |

## 💡 Request Examples

### Basic Text Chat ✅

```bash
curl --location "((SITE_URL))/api/v1/services/aigc/text-generation/generation" \
  --header "Authorization: Bearer $API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "qwen-plus",
    "input": {
      "messages": [
        {
          "role": "system",
          "content": "You are a helpful assistant."
        },
        {
          "role": "user",
          "content": "Who are you?"
        }
      ]
    }
  }'
```

## 📮 Request

### Endpoint

```
POST /api/v1/services/aigc/text-generation/generation
```

Create a model response for a given chat conversation.

### Authentication Method

Include the following in the request headers for API key authentication:

```
Authorization: Bearer $API_KEY
```

Where `$API_KEY` is your API key.

### Request Body Parameters

<ParameterTree>
  <ParameterField id="qwen-chat-heading-model-23" name="model" type="String" required>

    The ID of the model to use. For example: `qwen-plus`, `qwen-turbo`, etc.
  </ParameterField>
  <ParameterField id="qwen-chat-heading-input-24" name="input" type="Object" required>

    An object containing input messages.

    **input Properties:**

    <ParameterChildren>
      <ParameterField id="qwen-chat-table-messages-1" name="messages" type="Array" required>

        A list of messages comprising the conversation.
      </ParameterField>
    </ParameterChildren>

    <ParameterChildren>
      <ParameterField id="qwen-chat-heading-input-messages-25" name="messages" type="Array" required>

        The list of messages comprising the conversation so far.

        **Message Types:**

        | Message Type | Description |
        |---------|------|
        | **System message** | System message used to set the assistant's behavior and role. |
        | **User message** | Messages sent by the terminal user, containing prompts or additional context information. |
        | **Assistant message** | Messages sent by the model in response to user messages. |

        **System message Properties:**

        <ParameterChildren>
          <ParameterField id="qwen-chat-table-role-2" name="role" type="String" required>

            The role of the message author, here "system".
          </ParameterField>
          <ParameterField id="qwen-chat-table-content-3" name="content" type="String" required>

            The content of the system message.
          </ParameterField>
        </ParameterChildren>

        **User message Properties:**

        <ParameterChildren>
          <ParameterField id="qwen-chat-table-role-4" name="role" type="String" required>

            The role of the message author, here "user".
          </ParameterField>
          <ParameterField id="qwen-chat-table-content-5" name="content" type="String" required>

            The content of the user message.
          </ParameterField>
        </ParameterChildren>

        **Assistant message Properties:**

        <ParameterChildren>
          <ParameterField id="qwen-chat-table-role-6" name="role" type="String" required>

            The role of the message author, here "assistant".
          </ParameterField>
          <ParameterField id="qwen-chat-table-content-7" name="content" type="String">

            The content of the assistant message.
          </ParameterField>
        </ParameterChildren>
      </ParameterField>
    </ParameterChildren>
  </ParameterField>
  <ParameterField id="qwen-chat-heading-parameters-26" name="parameters" type="Object">

    Configuration for generation parameters.

    **parameters Properties:**

    <ParameterChildren>
      <ParameterField id="qwen-chat-table-result-format-8" name="result_format" type="String">

        Response format. Optional values: `message`, `text`. Default is `message`.
      </ParameterField>
      <ParameterField id="qwen-chat-table-temperature-9" name="temperature" type="Number">

        Sampling temperature, controlling the randomness of the output. Typically ranges from 0 to 2.
      </ParameterField>
      <ParameterField id="qwen-chat-table-top-p-10" name="top_p" type="Number">

        Nucleus sampling parameter, controlling the probability mass for sampling.
      </ParameterField>
      <ParameterField id="qwen-chat-table-max-tokens-11" name="max_tokens" type="Integer">

        Maximum number of tokens to generate.
      </ParameterField>
      <ParameterField id="qwen-chat-table-stop-12" name="stop" type="String or Array">

        Stop sequences, when the model generates these sequences, it stops generating.
      </ParameterField>
    </ParameterChildren>
  </ParameterField>
</ParameterTree>

## 📥 Response

### Text Generation Object

Returns a text generation object.

<ParameterTree>
  <ParameterField id="qwen-chat-heading-output-27" name="output" type="Object">

    Output object containing the generated text and choices.

    **output Properties:**

    <ParameterChildren>
      <ParameterField id="qwen-chat-table-text-13" name="text" type="String">

        The generated text content.
      </ParameterField>
      <ParameterField id="qwen-chat-table-finish-reason-14" name="finish_reason" type="String">

        The reason for completion.
      </ParameterField>
      <ParameterField id="qwen-chat-table-choices-15" name="choices" type="Array">

        A list of generated choices.
      </ParameterField>
    </ParameterChildren>

    <ParameterChildren>
      <ParameterField id="qwen-chat-heading-output-choices-28" name="choices" type="Array">

        A list of generated response options.

        **choice Properties:**

        <ParameterChildren>
          <ParameterField id="qwen-chat-table-finish-reason-16" name="finish_reason" type="String">

            The reason the model stopped generating tokens. Possible values: `stop` (natural stop), `length` (reached maximum length), etc.
          </ParameterField>
          <ParameterField id="qwen-chat-table-message-17" name="message" type="Object">

            The message generated by the model.

            <ParameterChildren>
              <ParameterField id="qwen-chat-table-message-role-18" name="role" type="String">

                The role of the message author, usually "assistant".
              </ParameterField>
              <ParameterField id="qwen-chat-table-message-content-19" name="content" type="String">

                The content of the message.
              </ParameterField>
            </ParameterChildren>
          </ParameterField>
        </ParameterChildren>
      </ParameterField>
    </ParameterChildren>
  </ParameterField>
  <ParameterField id="qwen-chat-heading-usage-29" name="usage" type="Object">

    Usage statistics for the completion request.

    **usage Properties:**

    <ParameterChildren>
      <ParameterField id="qwen-chat-table-input-tokens-20" name="input_tokens" type="Integer">

        The number of tokens in the input.
      </ParameterField>
      <ParameterField id="qwen-chat-table-output-tokens-21" name="output_tokens" type="Integer">

        The number of tokens in the generated completion.
      </ParameterField>
      <ParameterField id="qwen-chat-table-total-tokens-22" name="total_tokens" type="Integer">

        The total number of tokens used in the request (input + output).
      </ParameterField>
    </ParameterChildren>
  </ParameterField>
  <ParameterField id="qwen-chat-heading-code-30" name="code" type="String">

    Response code, usually an empty string indicating success.
  </ParameterField>
  <ParameterField id="qwen-chat-heading-message-31" name="message" type="String">

    Response message, usually an empty string indicating success.
  </ParameterField>
  <ParameterField id="qwen-chat-heading-request-id-32" name="request_id" type="String">

    The unique identifier for the request.
  </ParameterField>
</ParameterTree>
