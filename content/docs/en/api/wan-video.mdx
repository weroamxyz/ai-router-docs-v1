Wan provides text-to-video, image-to-video, first-and-last-frame, and reference-video generation through the same asynchronous video API.

---

## Supported Models

| Model | Mode | Description |
| --- | --- | --- |
| **wan2.5-t2v-preview** | Text-to-video | Wan 2.5 preview model |
| **wan2.6-t2v** | Text-to-video | Wan 2.6 model |
| **wan2.7-t2v** | Text-to-video | Wan 2.7 model |
| **wan2.5-i2v-preview** | Image-to-video | Wan 2.5 preview model |
| **wan2.6-i2v** | Image-to-video | Wan 2.6 model |
| **wan2.1-kf2v-plus** | First/last frames | Wan 2.1 keyframe model |
| **wan2.6-r2v** | Reference-to-video | Wan 2.6 character-reference model |

---

## Overview

All modes use `POST /v1/video/generations`. Select a mode with the model and its input fields: text-to-video uses a prompt alone, image-to-video adds `input_reference`, first-and-last-frame generation uses two URLs under `metadata.input`, and reference-to-video uses `metadata.input.reference_video_urls`.

Generation is asynchronous: submit a task, poll it by ID, and retrieve the result URL when it succeeds.

### Task Status Flow

```
queued → in_progress → completed
                ↓
              failed
```

## Model and Mode Differences

| Capability | Text-to-video | Image-to-video | First/last frames | Reference-to-video |
| --- | --- | --- | --- | --- |
| Input | Prompt | First-frame URL or data URI | First- and last-frame URLs | 1–3 reference-video URLs |
| Resolution field | `parameters.size` | `parameters.resolution` | Fixed at `720P` | `parameters.size` |
| Duration | `5`, `10`; `15` on 2.6 | `5`, `10`; `15` on 2.6 | Fixed at `5` | `5` or `10` |
| Audio | Wan 2.5/2.6 | Wan 2.5/2.6 | Not supported | Character voice from references |
| Multi-shot | Wan 2.6 with prompt extension | Wan 2.6 with prompt extension | Not supported | Supported |

## 1. Submit Video Generation Task (/v1/video/generations)

Choose the example matching your input assets and model family.

### Usage Examples

<ExampleTabs
  items={[

  ]}
>
  <ExampleTab id="wan-text-to-video-example">
    ```json
    {
      "prompt": "A marble hand statue stands in a shallow pool as vines move in the breeze.",
      "model": "wan2.6-t2v",
      "metadata": {
        "input": {
          "negative_prompt": "trees, animals"
        },
        "parameters": {
          "size": "1920*1080",
          "duration": 10,
          "audio": true,
          "prompt_extend": true
        }
      }
    }
    ```
  </ExampleTab>

  <ExampleTab id="wan-image-to-video-example">
    Provide the first frame as an HTTP(S) URL or an image data URI in
    `input_reference`. Plain, unprefixed base64 is not accepted.

    ```json
    {
      "prompt": "The light turns red and water begins overflowing around the statue.",
      "model": "wan2.5-i2v-preview",
      "input_reference": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA...",
      "metadata": {
        "input": {
          "negative_prompt": "blurry, low quality, distorted"
        },
        "parameters": {
          "resolution": "1080P",
          "duration": 5,
          "audio": true,
          "watermark": false
        }
      }
    }
    ```
  </ExampleTab>

  <ExampleTab id="wan-first-last-frame-example">
    `wan2.1-kf2v-plus` accepts URL inputs only. Resolution is fixed at `720P`,
    duration at five seconds, and audio and shot controls are unavailable.

    ```json
    {
      "prompt": "The hand-shaped statue cracks and collapses into the water.",
      "model": "wan2.1-kf2v-plus",
      "metadata": {
        "input": {
          "first_frame_url": "https://example.com/first-frame.png",
          "last_frame_url": "https://example.com/last-frame.png",
          "negative_prompt": "blurry, low quality"
        },
        "parameters": {
          "watermark": false,
          "prompt_extend": false,
          "seed": 12345
        }
      }
    }
    ```
  </ExampleTab>

  <ExampleTab id="wan-single-reference-example">
    Reference a character's appearance and voice with one video. In the prompt,
    refer to it as `character1`.

    ```json
    {
      "prompt": "character1 drinks bubble tea while dancing to the music.",
      "model": "wan2.6-r2v",
      "metadata": {
        "input": {
          "reference_video_urls": [
            "https://example.com/reference-video.mp4"
          ]
        },
        "parameters": {
          "size": "1280*720",
          "duration": 5,
          "shot_type": "multi"
        }
      }
    }
    ```
  </ExampleTab>

  <ExampleTab id="wan-multiple-references-example">
    Reference videos map by array position to `character1`, `character2`, and
    `character3` in the prompt.

    ```json
    {
      "prompt": "character1 and character2 talk to each other in an office.",
      "model": "wan2.6-r2v",
      "metadata": {
        "input": {
          "reference_video_urls": [
            "https://example.com/character1.mp4",
            "https://example.com/character2.mp4"
          ],
          "negative_prompt": "white walls"
        },
        "parameters": {
          "size": "1280*720",
          "duration": 10,
          "shot_type": "multi",
          "watermark": true
        }
      }
    }
    ```
  </ExampleTab>
</ExampleTabs>

### Complete Request

```bash
curl -X POST "((SITE_URL))/v1/video/generations" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer API_KEY" \
  -d @request-body.json
```

### Request Headers

| Header | Required | Value |
| --- | --- | --- |
| `Content-Type` | Yes | `application/json` |
| `Authorization` | Yes | `Bearer API_KEY` |

### Request Body Fields

<ParameterTree>
  <ParameterField id="wan-request-model" name="model" type="string" required>
    Select a supported model whose suffix matches the intended mode: `t2v`,
    `i2v`, `kf2v`, or `r2v`.
  </ParameterField>
  <ParameterField id="wan-request-prompt" name="prompt" type="string" required>
    Description of the output video. Reference-video prompts can use
    `character1` through `character3` to identify videos by array position.
  </ParameterField>
  <ParameterField id="wan-request-input-reference" name="input_reference" type="string">
    First-frame image for image-to-video. Accepts an HTTP(S) URL or a data URI
    such as `data:image/png;base64,...`.
  </ParameterField>
  <ParameterField id="wan-request-metadata" name="metadata" type="object">
    Container for fields from the native Wan request format.
    <ParameterChildren>
      <ParameterField id="wan-request-input" name="input" type="object">
        Input assets and prompt controls.
        <ParameterChildren>
          <ParameterField id="wan-input-negative-prompt" name="negative_prompt" type="string">
            Content or visual qualities to exclude.
          </ParameterField>
          <ParameterField id="wan-input-audio-url" name="audio_url" type="string">
            Custom audio URL for synchronization. Supported by Wan 2.5 and 2.6
            text/image models. When present, it overrides `parameters.audio`.
          </ParameterField>
          <ParameterField id="wan-input-img-url" name="img_url" type="string">
            Alternative first-frame URL for image-to-video. The top-level
            `input_reference` field is generally simpler.
          </ParameterField>
          <ParameterField id="wan-input-first-frame" name="first_frame_url" type="string">
            Required first-frame URL for `wan2.1-kf2v-plus`. Base64 is not
            supported in this mode.
          </ParameterField>
          <ParameterField id="wan-input-last-frame" name="last_frame_url" type="string">
            Required last-frame URL for `wan2.1-kf2v-plus`. Base64 is not
            supported in this mode.
          </ParameterField>
          <ParameterField id="wan-input-reference-videos" name="reference_video_urls" type="string[]">
            One to three HTTP(S) MP4 or MOV URLs for `wan2.6-r2v`. Each video
            must contain one character, last 2–30 seconds, and be no larger than
            100 MB. Array order maps to character identifiers in the prompt.
          </ParameterField>
        </ParameterChildren>
      </ParameterField>
      <ParameterField id="wan-request-parameters" name="parameters" type="object">
        Output and generation controls.
        <ParameterChildren>
          <ParameterField id="wan-parameters-prompt-extend" name="prompt_extend" type="boolean">
            Enable intelligent prompt rewriting.
          </ParameterField>
          <ParameterField id="wan-parameters-watermark" name="watermark" type="boolean">
            Add a watermark to the output video.
          </ParameterField>
          <ParameterField id="wan-parameters-seed" name="seed" type="integer">
            Random seed from `0` to `2147483647`. A fixed seed improves, but
            does not guarantee, reproducibility.
          </ParameterField>
          <ParameterField id="wan-parameters-size" name="size" type="string">
            Output dimensions for text-to-video and reference-to-video.

            - 480P (Wan 2.5 text only): `832*480`, `480*832`, `624*624`
            - 720P: `1280*720`, `720*1280`, `960*960`, `1088*832`, `832*1088`
            - 1080P: `1920*1080`, `1080*1920`, `1440*1440`, `1632*1248`,
              `1248*1632`

            Reference-to-video defaults to `1920*1080`.
          </ParameterField>
          <ParameterField id="wan-parameters-resolution" name="resolution" type="string">
            Image-to-video resolution: `480P` on Wan 2.5, or `720P`/`1080P` on
            supported models. First-and-last-frame output is fixed at `720P`.
          </ParameterField>
          <ParameterField id="wan-parameters-duration" name="duration" type="integer">
            Output duration. Text/image modes accept `5` or `10`, plus `15` on
            Wan 2.6. Reference-to-video accepts `5` or `10`; keyframe mode is
            fixed at `5`.
          </ParameterField>
          <ParameterField id="wan-parameters-audio" name="audio" type="boolean">
            Generate matching audio when no `audio_url` is provided. Supported
            by Wan 2.5 and 2.6 text/image models; unavailable in keyframe mode.
          </ParameterField>
          <ParameterField id="wan-parameters-shot-type" name="shot_type" type="string">
            `single` or `multi`. Supported by Wan 2.6 text/image models when
            `prompt_extend` is enabled, and by `wan2.6-r2v`. Unavailable in
            keyframe mode.
          </ParameterField>
        </ParameterChildren>
      </ParameterField>
    </ParameterChildren>
  </ParameterField>
</ParameterTree>

> Audio priority is `metadata.input.audio_url` over `metadata.parameters.audio`. Omit both (or set `audio` to `false`) for silent video, set `audio` to `true` for generated audio, or provide `audio_url` for custom synchronized audio.

## Important Notes

1. Image data in `input_reference` must be an HTTP(S) URL or a complete data URI; plain base64 is not accepted.
2. `wan2.1-kf2v-plus` first/last-frame inputs accept URLs only.
3. Task IDs and output URLs are retained for 24 hours.
4. Reference-to-video accepts one to three reference videos. Each should contain one character; array order defines `character1`, `character2`, and `character3`.
5. Reference-to-video billing uses the combined input and output duration. Truncated input durations contribute at most five billable seconds, and failed generations are not billed.
6. Prompts, input assets, and output videos undergo content moderation.
