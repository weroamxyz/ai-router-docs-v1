# Grok 视频接口文档

xAI 的 Grok Imagine 提供视频生成模型。本文档描述了使用 Grok 视频模型进行视频生成的 API 接口。所有视频生成调用都使用相同的 `/v1/video/generations` 端点，根据用例使用不同的参数。

---

## 支持的模型

目前支持的模型包括：

| 模型 | 描述 |
| --- | --- |
| **grok-imagine-video** | Grok Imagine 视频生成模型（文生视频、图生视频、参考生视频） |

---

## 概述

Grok 视频生成功能提供异步任务处理机制：

1. 提交任务：发送文本提示词（以及可选的一张或多张图片），创建视频任务
2. 查询状态：通过任务 ID 查询生成进度和状态
3. 获取结果：任务完成后获取生成的视频文件

同一个 `/v1/video/generations` 端点根据 `images` 是否存在以及 `metadata.imageMode` 的取值，服务于三种用例：不传 `images` 为文生视频；传入 `images` 且 `metadata.imageMode` 省略或为 `"keyframe"`（默认值）为图生视频，此时仅使用第一张图片；传入 `images` 且 `metadata.imageMode` 为 `"reference"` 为参考生视频。

### 任务状态流转

```
queued → in_progress → completed
                ↓
            failed
```

- queued: 任务已提交，等待处理
- in_progress: 任务正在处理中
- completed: 任务成功完成，视频已生成
- failed: 任务失败

> **注意：** Grok 视频不支持推送回调。请轮询 [2. 查询任务状态](#2-查询任务状态-v1videogenerationstask_id) 直到任务达到终止状态。

## 1. 提交视频生成任务 (/v1/video/generations)

请选择与视频生成方式匹配的示例，再根据实际场景调整请求体。

### 调用示例

<ExampleTabs items={['文生视频', '图生视频', '参考生视频']}>
  <ExampleTab id="text-to-video-example">
    文生视频仅使用 `prompt` 与 `model`，不传 `images`。顶层可选字段包括
    `duration` 和 `size`，`aspect_ratio` 通过 `metadata` 设置。

    **请求体：**

    ```json
    {
      "prompt": "A glowing crystal-powered rocket launching from the red dunes of Mars",
      "model": "grok-imagine-video",
      "duration": 10,
      "size": "720p",
      "metadata": {
        "aspect_ratio": "16:9"
      }
    }
    ```

    **请求参数：**

    <ParameterTree locale="zh">
      <ParameterField id="text-prompt" name="prompt" type="string" required>
        视频的文本提示词。
      </ParameterField>
      <ParameterField id="text-model" name="model" type="string" required>
        模型名称。使用 `grok-imagine-video`。
      </ParameterField>
      <ParameterField id="text-duration" name="duration" type="integer" required>
        视频时长（秒）。取值为闭区间 `1`～`15` 的整数。
      </ParameterField>
      <ParameterField id="text-size" name="size" type="string">
        输出分辨率。默认为 `480p`；可选 `480p`、`720p` 或 `1080p`。
      </ParameterField>
      <ParameterField id="text-metadata" name="metadata" type="object">
        生成请求的额外元数据。
        <ParameterChildren>
          <ParameterField
            id="text-metadata-aspect-ratio"
            name="aspect_ratio"
            type="string"
          >
            视频宽高比。省略时 xAI 使用 `16:9`。可选 `1:1`、`16:9`、
            `9:16`、`4:3`、`3:4`、`3:2` 或 `2:3`。
          </ParameterField>
        </ParameterChildren>
      </ParameterField>
    </ParameterTree>
  </ExampleTab>

  <ExampleTab id="image-to-video-example">
    在 `images` 中传入一个或多个图像 URL（或 base64 数据 URI），并省略
    `metadata.imageMode` 或将其设为 `"keyframe"`（默认值）。仅使用数组中的
    **第一张**图像——该图像将成为视频的首帧并被锁定；其余图像将被忽略。

    **请求体：**

    ```json
    {
      "prompt": "The rocket's engines ignite and it lifts off in a cloud of dust",
      "model": "grok-imagine-video",
      "images": ["https://example.com/rocket-on-launchpad.jpg"],
      "duration": 8,
      "size": "720p",
      "metadata": {
        "aspect_ratio": "16:9"
      }
    }
    ```

    **请求参数：**

    <ParameterTree locale="zh">
      <ParameterField id="image-prompt" name="prompt" type="string" required>
        描述图像应如何动起来的文本提示词。
      </ParameterField>
      <ParameterField id="image-model" name="model" type="string" required>
        模型名称。使用 `grok-imagine-video`。
      </ParameterField>
      <ParameterField id="image-images" name="images" type="string[]" required>
        一个或多个图像 URL 或 base64 数据 URI。仅使用**第一张**图像，
        它将成为锁定的首帧。
      </ParameterField>
      <ParameterField id="image-duration" name="duration" type="integer" required>
        视频时长（秒）。取值为闭区间 `1`～`15` 的整数。
      </ParameterField>
      <ParameterField id="image-size" name="size" type="string">
        输出分辨率。默认为 `480p`；可选 `480p`、`720p` 或 `1080p`。
      </ParameterField>
      <ParameterField id="image-metadata" name="metadata" type="object">
        生成请求的额外元数据。
        <ParameterChildren>
          <ParameterField
            id="image-metadata-image-mode"
            name="imageMode"
            type="string"
          >
            图像处理模式。默认为 `keyframe`；图生视频时使用 `keyframe`
            或省略此字段。
          </ParameterField>
          <ParameterField
            id="image-metadata-aspect-ratio"
            name="aspect_ratio"
            type="string"
          >
            视频宽高比。默认为 `16:9`；可选 `1:1`、`16:9`、`9:16`、
            `4:3`、`3:4`、`3:2` 或 `2:3`。
          </ParameterField>
        </ParameterChildren>
      </ParameterField>
    </ParameterTree>

    > **注意：** 图生视频不支持单独传入末帧图像。如需使用多张图片而不锁定画面，
    > 请切换到**参考生视频**标签页。
  </ExampleTab>

  <ExampleTab id="reference-to-video-example">
    将 `metadata.imageMode` 设置为 `"reference"`，此时 `images` 中的每个 URL 都被视为
    **参考图**，用于影响视频生成而不锁定任何画面。可在提示词中使用

    **请求体：**

    ```json
    {
      "prompt": "The model from <IMAGE_1> walks the runway wearing the shirt from <IMAGE_2>",

        "https://example.com/shirt-reference.jpg"
      ],
      "duration": 10,
      "size": "720p",

        "aspect_ratio": "16:9"
      }

    ```

    **请求参数：**

    <ParameterTree locale="zh">
      <ParameterField id="reference-prompt" name="prompt" type="string" required>
        文本提示词。使用 `<IMAGE_1>` 至 `<IMAGE_N>` 按数组顺序引用图片。
      </ParameterField>
      <ParameterField id="reference-model" name="model" type="string" required>
        模型名称。使用 `grok-imagine-video`。
      </ParameterField>
      <ParameterField
        id="reference-images"
        name="images"
        type="string[]"
        required
      >
        一个或多个参考图像 URL 或 base64 数据 URI。
      </ParameterField>
      <ParameterField
        id="reference-duration"
        name="duration"
        type="integer"
        required
      >
        视频时长（秒）。取值为闭区间 `1`～`15` 的整数。
      </ParameterField>
      <ParameterField id="reference-size" name="size" type="string">
        输出分辨率。默认为 `480p`；可选 `480p`、`720p` 或 `1080p`。
      </ParameterField>
      <ParameterField id="reference-metadata" name="metadata" type="object">
        参考图像处理的元数据。本模式必须包含 `imageMode`。
        <ParameterChildren>
          <ParameterField
            id="reference-metadata-image-mode"

            type="string"

          <ParameterField
            id="reference-metadata-aspect-ratio"

            视频宽高比。默认为 `16:9`；可选 `1:1`、`16:9`、`9:16`、
            `4:3`、`3:4`、`3:2` 或 `2:3`。
          </ParameterField>
        </ParameterChildren>
      </ParameterField>

### 完整请求：

```bash
curl -X POST "((SITE_URL))/v1/video/generations" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer API_KEY" \
  -d @request-body.json
```

### 接口地址:

```
POST /v1/video/generations
```

## 2. 查询任务状态 (/v1/video/generations/\{task_id\})

### 完整请求：

```bash
curl -X GET "((SITE_URL))/v1/video/generations/TASK_ID" \
  -H "Authorization: Bearer API_KEY"
```

### 接口地址:

```
GET /v1/video/generations/{task_id}
```

### 请求头:

<ParameterTree>
  <ParameterField id="grok-video-table-authorization-3" name="Authorization" type="string" required>

    Bearer API_KEY
  </ParameterField>
</ParameterTree>

### 路径参数:

<ParameterTree>
  <ParameterField id="grok-video-table-task-id-4" name="task_id" type="string" required>

    任务 ID
  </ParameterField>
</ParameterTree>

### 响应示例：

<ExampleTabs items={['处理中', '成功']}>
  <ExampleTab id="processing-response-example">
    ```json
    {
      "code": "success",
      "message": "",
      "data": {
        "task_id": "<TASK_ID>",
        "action": "generate",
        "status": "IN_PROGRESS",
        "fail_reason": "",
        "submit_time": 1776717808,
        "start_time": 1776717809,
        "finish_time": 0,
        "progress": "50%",
        "data": {
          "status": "pending",
          "model": "grok-imagine-video"
        }
      }
    }
    ```
  </ExampleTab>

  <ExampleTab id="success-response-example">
    > **注意：** 任务成功时，`data.fail_reason` 会包含视频下载 URL 而非错误信息。
    > 获取生成的视频时，建议优先使用 `data.data.video.url`。

    ```json
    {
      "code": "success",
      "message": "",
      "data": {
        "task_id": "<TASK_ID>",
        "action": "generate",
        "status": "SUCCESS",
        "fail_reason": "<VIDEO_URL>",
        "submit_time": 1776717808,
        "start_time": 1776717809,
        "finish_time": 1776717962,
        "progress": "100%",
        "data": {
          "status": "done",
          "model": "grok-imagine-video",
          "video": {
            "url": "<VIDEO_URL>",
            "duration": 8,
            "respect_moderation": true
          },
          "usage": {
            "cost_in_usd_ticks": 2500000000
          }
        }
      }
    }
    ```
  </ExampleTab>
