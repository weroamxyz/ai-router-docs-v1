## 简介

Google Gemini API 支持使用图片、音频、代码、工具等生成内容。给定输入 GenerateContentRequest 生成模型响应。支持文本生成、视觉理解、音频处理、长上下文、代码执行、JSON 模式、函数调用等多种功能。

## 支持的模型

目前支持的模型包括：

| 模型 | 描述 |
| --- | --- |
| **gemini-3-flash-preview** | 以更低成本媲美更大模型性能的前沿级模型（预览版） |
| **gemini-3.1-flash-lite** | 以更低成本媲美更大模型性能的前沿级模型 |
| **gemini-3.1-pro-preview** | 具备高级智能、复杂问题解决能力，以及强大的智能体与氛围编码能力（预览版） |
| **gemini-3.5-flash-lite** | 3.5 系列中速度最快、性价比最高的模型，专为高吞吐执行打造 |
| **gemini-3.5-flash** | 上一代 Flash 模型，为常规高吞吐工作负载提供基础速度和性能 |
| **gemini-3.6-flash** | 前一代 Flash 模型，在通用智能体和日常任务中兼顾速度与多模态能力 |
| **gemini-3.7-flash** | 智能的日常主力模型，专为复杂编码、智能体工作流和可靠的多步执行打造 |
| **gemini-3.8-flash** | 迄今最智能的 Flash 模型，专为长周期编码和自主智能体打造 |

## 请求

### 端点

#### 生成内容
```
POST ((SITE_URL))/v1beta/{model=models/*}:generateContent
```

#### 流式生成内容
```
POST ((SITE_URL))/v1beta/{model=models/*}:streamGenerateContent
```

### 鉴权方法

在请求URL参数中包含API密钥：

```
?key=$API_KEY
```

其中 `$API_KEY` 是您的 Google AI API 密钥。

    **HarmCategory 枚举值：**

    - `HARM_CATEGORY_HARASSMENT`: 骚扰内容
    - `HARM_CATEGORY_HATE_SPEECH`: 仇恨言论和内容
    - `HARM_CATEGORY_SEXUALLY_EXPLICIT`: 露骨色情内容
    - `HARM_CATEGORY_DANGEROUS_CONTENT`: 危险内容
    - `HARM_CATEGORY_CIVIC_INTEGRITY`: 可能用于破坏公民诚信的内容

    **HarmBlockThreshold 枚举值：**

    - `BLOCK_LOW_AND_ABOVE`: 允许发布评分为 NEGLIGIBLE 的内容
    - `BLOCK_MEDIUM_AND_ABOVE`: 允许发布评分为 NEGLIGIBLE 和 LOW 的内容
    - `BLOCK_ONLY_HIGH`: 允许发布风险等级为 NEGLIGIBLE、LOW 和 MEDIUM 的内容
    - `BLOCK_NONE`: 允许所有内容
    - `OFF`: 关闭安全过滤器

    **HarmBlockThreshold 完整枚举值：**

    - `HARM_BLOCK_THRESHOLD_UNSPECIFIED`: 未指定阈值
    - `BLOCK_LOW_AND_ABOVE`: 屏蔽低概率及以上的有害内容，只允许 NEGLIGIBLE 级别的内容
    - `BLOCK_MEDIUM_AND_ABOVE`: 屏蔽中等概率及以上的有害内容，允许 NEGLIGIBLE 和 LOW 级别的内容
    - `BLOCK_ONLY_HIGH`: 只屏蔽高概率的有害内容，允许 NEGLIGIBLE、LOW 和 MEDIUM 级别的内容
    - `BLOCK_NONE`: 不屏蔽任何内容，允许所有级别的内容
    - `OFF`: 完全关闭安全过滤器

## 功能交互

以下字段并不是额外的顶级参数。每项功能都由请求参数树中的字段启用，并在适用时通过 `GenerateContentResponse` 中对应的路径返回数据。

### 代码执行

通过 `tools[].codeExecution` 启用代码执行。生成的代码及其执行结果会作为内容部分返回：

```text
请求：tools[].codeExecution
响应：candidates[].content.parts[].executableCode
      candidates[].content.parts[].codeExecutionResult
```

```json
{
  "tools": [
    {
      "codeExecution": {}
    }
  ],
  "contents": [
    {
      "parts": [
        {
          "text": "计算斐波那契数列的第十项。"
        }
      ]
    }
  ]
}
```

### 接地和网址上下文

通过 `tools` 数组启用 Google 搜索接地或网址检索。支持性来源和检索状态会作为候选项元数据返回：

```text
请求：tools[].googleSearch
响应：candidates[].groundingMetadata

请求：tools[].urlContext
响应：candidates[].urlContextMetadata
```

`groundingChunks` 包含检索到的来源，`groundingSupports` 将生成答案的片段与这些来源相关联。

### 思考功能

思考功能在 `generationConfig` 中配置：

```text
请求：generationConfig.thinkingConfig
响应：candidates[].content.parts[]   （请求且可用时返回思考部分）
      usageMetadata.thoughtsTokenCount
```

使用 `includeThoughts` 请求可用的思考摘要。只有支持相应控制项的模型才能使用 `thinkingBudget` 或 `thinkingLevel`。

### 语音生成

语音输出需要音频响应模态和语音配置：

```text
请求：generationConfig.responseModalities
      generationConfig.speechConfig
响应：candidates[].content.parts[]   （音频媒体部分）
```

单语音配置位于 `speechConfig.voiceConfig`。多说话人配置位于 `speechConfig.multiSpeakerVoiceConfig`；两者不能同时使用。

### 对数概率

在请求中启用对数概率，然后从每个候选项中读取 token 级结果：

```text
请求：generationConfig.responseLogprobs
      generationConfig.logprobs
响应：candidates[].avgLogprobs
      candidates[].logprobsResult
```

只有启用 `responseLogprobs` 后才能使用 `logprobs`。

### 安全性

`safetySettings` 控制应用于请求和生成候选项的屏蔽阈值。评级会在响应中分别返回：

```text
请求：safetySettings[]
响应：promptFeedback.safetyRatings[]
      candidates[].safetyRatings[]
```

被屏蔽的提示通过 `promptFeedback.blockReason` 报告。因安全原因停止的候选项通过 `finishReason` 和 `safetyRatings` 报告。

### 多模态处理

将内联媒体或已上传媒体作为内容部分提供。分辨率属于输入设置，而模态 token 数量属于响应元数据：

```text
请求：contents[].parts[].inlineData
      contents[].parts[].fileData
      generationConfig.mediaResolution
响应：usageMetadata.promptTokensDetails[]
      usageMetadata.candidatesTokensDetails[]
```

支持的媒体类型取决于所选模型。常见模态包括文本、图片、音频、视频和 PDF 文档。

## 错误处理

### 常见错误码

| 错误码 | 描述 |
|--------|------|
| `400` | 请求格式错误或参数无效 |
| `401` | API密钥无效或缺失 |
| `403` | 权限不足或配额限制 |
| `429` | 请求频率过高 |
| `500` | 服务器内部错误 |

### 详细错误码说明

| 错误码 | 状态 | 描述 | 解决方案 |
|--------|------|------|----------|
| `400` | `INVALID_ARGUMENT` | 请求参数无效或格式错误 | 检查请求参数格式和必需字段 |
| `400` | `FAILED_PRECONDITION` | 请求的前置条件不满足 | 确保满足API调用的前置条件 |
| `401` | `UNAUTHENTICATED` | API密钥无效、缺失或已过期 | 检查API密钥的有效性和格式 |
| `403` | `PERMISSION_DENIED` | 权限不足或配额已用完 | 检查API密钥权限或升级配额 |
| `404` | `NOT_FOUND` | 指定的模型或资源不存在 | 验证模型名称和资源路径 |
| `413` | `PAYLOAD_TOO_LARGE` | 请求体太大 | 减少输入内容大小或分批处理 |
| `429` | `RESOURCE_EXHAUSTED` | 请求频率超限或配额不足 | 降低请求频率或等待配额重置 |
| `500` | `INTERNAL` | 服务器内部错误 | 重试请求，如持续出现联系支持 |
| `503` | `UNAVAILABLE` | 服务暂时不可用 | 等待一段时间后重试 |
| `504` | `DEADLINE_EXCEEDED` | 请求超时 | 减少输入大小或重试请求 |
