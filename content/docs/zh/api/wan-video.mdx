Wan 通过同一套异步视频 API 提供文生视频、图生视频、首末帧生成和参考视频生成能力。

---

## 支持的模型

| 模型 | 模式 | 说明 |
| --- | --- | --- |
| **wan2.5-t2v-preview** | 文生视频 | Wan 2.5 预览模型 |
| **wan2.6-t2v** | 文生视频 | Wan 2.6 模型 |
| **wan2.7-t2v** | 文生视频 | Wan 2.7 模型 |
| **wan2.5-i2v-preview** | 图生视频 | Wan 2.5 预览模型 |
| **wan2.6-i2v** | 图生视频 | Wan 2.6 模型 |
| **wan2.1-kf2v-plus** | 首末帧 | Wan 2.1 关键帧模型 |
| **wan2.6-r2v** | 参考生视频 | Wan 2.6 角色参考模型 |

---

## 概述

所有模式都使用 `POST /v1/video/generations`。模型和输入字段决定生成模式：文生视频仅使用提示词；图生视频增加 `input_reference`；首末帧生成在 `metadata.input` 中传入两个 URL；参考生视频则使用 `metadata.input.reference_video_urls`。

视频生成采用异步流程：提交任务、使用任务 ID 轮询状态，并在成功后获取结果 URL。

### 任务状态流转

```
queued → in_progress → completed
                ↓
              failed
```

## 接口列表

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | [/v1/video/generations](#1-提交视频生成任务-v1videogenerations) | 提交视频生成任务 |
| GET | [/v1/video/generations/\{task_id\}](#2-查询任务状态-v1videogenerationstask_id) | 查询任务状态并获取结果 |

## 模型与模式差异

| 能力 | 文生视频 | 图生视频 | 首末帧 | 参考生视频 |
| --- | --- | --- | --- | --- |
| 输入 | 提示词 | 首帧 URL 或数据 URI | 首帧和末帧 URL | 1～3 个参考视频 URL |
| 分辨率字段 | `parameters.size` | `parameters.resolution` | 固定 `720P` | `parameters.size` |
| 时长 | `5`、`10`；2.6 支持 `15` | `5`、`10`；2.6 支持 `15` | 固定 `5` | `5` 或 `10` |
| 音频 | Wan 2.5/2.6 | Wan 2.5/2.6 | 不支持 | 从参考视频提取角色声音 |
| 多镜头 | Wan 2.6，需开启提示词扩写 | Wan 2.6，需开启提示词扩写 | 不支持 | 支持 |

## 1. 提交视频生成任务 (/v1/video/generations)

选择与输入素材和模型系列匹配的示例。

### 调用示例

<ExampleTabs
  items={['文生视频', '图生视频', '首末帧', '单参考视频', '多参考视频']}
>
  <ExampleTab id="wan-text-to-video-example">
    ```json
    {
      "prompt": "A marble hand statue stands in a shallow pool as vines move in the breeze.",
      "model": "wan2.6-t2v",
      "metadata": {
        "input": {
          "negative_prompt": "trees, animals"
        },
        "parameters": {
          "size": "1920*1080",
          "duration": 10,
          "audio": true,
          "prompt_extend": true
        }
      }
    }
    ```
  </ExampleTab>

  <ExampleTab id="wan-image-to-video-example">
    在 `input_reference` 中提供 HTTP(S) URL 或图像数据 URI 作为首帧。不接受未包含 MIME 前缀的纯 base64 数据。

    ```json
    {
      "prompt": "The light turns red and water begins overflowing around the statue.",
      "model": "wan2.5-i2v-preview",
      "input_reference": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA...",
      "metadata": {
        "input": {
          "negative_prompt": "blurry, low quality, distorted"
        },
        "parameters": {
          "resolution": "1080P",
          "duration": 5,
          "audio": true,
          "watermark": false
        }
      }
    }
    ```
  </ExampleTab>

  <ExampleTab id="wan-first-last-frame-example">
    `wan2.1-kf2v-plus` 仅接受 URL。分辨率固定为 `720P`，时长固定为五秒，且不支持音频和镜头控制。

    ```json
    {
      "prompt": "The hand-shaped statue cracks and collapses into the water.",
      "model": "wan2.1-kf2v-plus",
      "metadata": {
        "input": {
          "first_frame_url": "https://example.com/first-frame.png",
          "last_frame_url": "https://example.com/last-frame.png",
          "negative_prompt": "blurry, low quality"
        },
        "parameters": {
          "watermark": false,
          "prompt_extend": false,
          "seed": 12345
        }
      }
    }
    ```
  </ExampleTab>

  <ExampleTab id="wan-single-reference-example">
    使用一段视频参考角色的外观和声音，并在提示词中用 `character1` 指代该角色。

    ```json
    {
      "prompt": "character1 drinks bubble tea while dancing to the music.",
      "model": "wan2.6-r2v",
      "metadata": {
        "input": {
          "reference_video_urls": [
            "https://example.com/reference-video.mp4"
          ]
        },
        "parameters": {
          "size": "1280*720",
          "duration": 5,
          "shot_type": "multi"
        }
      }
    }
    ```
  </ExampleTab>

  <ExampleTab id="wan-multiple-references-example">
    参考视频按数组顺序映射到提示词中的 `character1`、`character2` 和 `character3`。

    ```json
    {
      "prompt": "character1 and character2 talk to each other in an office.",
      "model": "wan2.6-r2v",
      "metadata": {
        "input": {
          "reference_video_urls": [
            "https://example.com/character1.mp4",
            "https://example.com/character2.mp4"
          ],
          "negative_prompt": "white walls"
        },
        "parameters": {
          "size": "1280*720",
          "duration": 10,
          "shot_type": "multi",
          "watermark": true
        }
      }
    }
    ```
  </ExampleTab>
</ExampleTabs>

### 完整请求

```bash
curl -X POST "((SITE_URL))/v1/video/generations" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer API_KEY" \
  -d @request-body.json
```

### 请求头

| 请求头 | 必填 | 值 |
| --- | --- | --- |
| `Content-Type` | 是 | `application/json` |
| `Authorization` | 是 | `Bearer API_KEY` |

### 请求体字段

<ParameterTree locale="zh">
  <ParameterField id="wan-request-model" name="model" type="string" required>
    选择后缀与目标模式匹配的模型：`t2v`、`i2v`、`kf2v` 或 `r2v`。
  </ParameterField>
  <ParameterField id="wan-request-prompt" name="prompt" type="string" required>
    描述目标视频。参考生视频可使用 `character1` 至 `character3`，按数组顺序指代参考视频。
  </ParameterField>
  <ParameterField id="wan-request-input-reference" name="input_reference" type="string">
    图生视频的首帧图像。接受 HTTP(S) URL 或 `data:image/png;base64,...` 形式的数据 URI。
  </ParameterField>
  <ParameterField id="wan-request-metadata" name="metadata" type="object">
    Wan 原生请求字段的容器。
    <ParameterChildren>
      <ParameterField id="wan-request-input" name="input" type="object">
        输入素材和提示词控制。
        <ParameterChildren>
          <ParameterField id="wan-input-negative-prompt" name="negative_prompt" type="string">
            不希望出现在视频中的内容或视觉特征。
          </ParameterField>
          <ParameterField id="wan-input-audio-url" name="audio_url" type="string">
            用于音画同步的自定义音频 URL。Wan 2.5 和 2.6 文本/图像模型支持；传入后会覆盖 `parameters.audio`。
          </ParameterField>
          <ParameterField id="wan-input-img-url" name="img_url" type="string">
            图生视频的另一种首帧 URL 写法。通常建议使用顶层 `input_reference`。
          </ParameterField>
          <ParameterField id="wan-input-first-frame" name="first_frame_url" type="string">
            `wan2.1-kf2v-plus` 必填的首帧 URL，此模式不支持 base64。
          </ParameterField>
          <ParameterField id="wan-input-last-frame" name="last_frame_url" type="string">
            `wan2.1-kf2v-plus` 必填的末帧 URL，此模式不支持 base64。
          </ParameterField>
          <ParameterField id="wan-input-reference-videos" name="reference_video_urls" type="string[]">
            `wan2.6-r2v` 使用的 1～3 个 HTTP(S) MP4 或 MOV URL。每段视频只能包含一个角色，时长 2～30 秒，文件不超过 100 MB。数组顺序与提示词中的角色编号对应。
          </ParameterField>
        </ParameterChildren>
      </ParameterField>
      <ParameterField id="wan-request-parameters" name="parameters" type="object">
        输出和生成控制。
        <ParameterChildren>
          <ParameterField id="wan-parameters-prompt-extend" name="prompt_extend" type="boolean">
            是否启用智能提示词扩写。
          </ParameterField>
          <ParameterField id="wan-parameters-watermark" name="watermark" type="boolean">
            是否为输出视频添加水印。
          </ParameterField>
          <ParameterField id="wan-parameters-seed" name="seed" type="integer">
            `0`～`2147483647` 的随机种子。固定种子可提高复现性，但不保证结果完全一致。
          </ParameterField>
          <ParameterField id="wan-parameters-size" name="size" type="string">
            文生视频和参考生视频的输出尺寸。

            - 480P（仅 Wan 2.5 文生视频）：`832*480`、`480*832`、`624*624`
            - 720P：`1280*720`、`720*1280`、`960*960`、`1088*832`、`832*1088`
            - 1080P：`1920*1080`、`1080*1920`、`1440*1440`、`1632*1248`、
              `1248*1632`

            参考生视频默认为 `1920*1080`。
          </ParameterField>
          <ParameterField id="wan-parameters-resolution" name="resolution" type="string">
            图生视频分辨率：Wan 2.5 可选 `480P`，支持的模型可选 `720P` 或 `1080P`。首末帧模式固定为 `720P`。
          </ParameterField>
          <ParameterField id="wan-parameters-duration" name="duration" type="integer">
            输出时长。文生/图生模式可选 `5` 或 `10`，Wan 2.6 还支持 `15`；参考生视频可选 `5` 或 `10`；首末帧固定为 `5`。
          </ParameterField>
          <ParameterField id="wan-parameters-audio" name="audio" type="boolean">
            未传 `audio_url` 时生成匹配音频。Wan 2.5 和 2.6 文本/图像模型支持；首末帧模式不可用。
          </ParameterField>
          <ParameterField id="wan-parameters-shot-type" name="shot_type" type="string">
            可选 `single` 或 `multi`。Wan 2.6 文本/图像模型需同时开启 `prompt_extend`；`wan2.6-r2v` 也支持；首末帧模式不可用。
          </ParameterField>
        </ParameterChildren>
      </ParameterField>
    </ParameterChildren>
  </ParameterField>
</ParameterTree>

> 音频参数优先级为 `metadata.input.audio_url` 高于 `metadata.parameters.audio`。省略两者（或将 `audio` 设为 `false`）会生成无声视频；`audio: true` 会自动生成音频；传入 `audio_url` 则使用自定义同步音频。

## 重要提示

1. `input_reference` 中的图像必须是 HTTP(S) URL 或完整数据 URI，不接受纯 base64。
2. `wan2.1-kf2v-plus` 的首末帧输入仅接受 URL。
3. 任务 ID 和输出 URL 保留 24 小时。
4. 参考生视频支持 1～3 段参考视频。每段视频应只包含一个角色；数组顺序决定 `character1`、`character2` 和 `character3`。
5. 参考生视频按输入与输出总时长计费。截断后的输入视频最多计入五秒，生成失败不计费。
6. 提示词、输入素材和输出视频都会经过内容审核。
